AskForever - in-game AI assistant for World of Warcraft: WoW Forever
The addon alone builds a prompt with your character context that you can copy.
For answers inside the game, keep the free AskForever companion for Windows
or Linux running while you play; download it from:
https://github.com/warcrafted-server/AskForever/releases
Linux (first beta) installation guide:
https://github.com/warcrafted-server/AskForever/blob/main/docs/INSTALL_LINUX.md
The companion needs a free Google Gemini API key: create it first, and the first
time you open the companion it will ask you to paste it.
The docs/ folder has the full installation guide and the security and data
transparency report: docs/INSTALL_GUIDE.md, docs/GUIA_INSTALACION.md,
docs/SECURITY_TRANSPARENCY.md, docs/SEGURIDAD_TRANSPARENCIA.md.
In the game, type /af help for the commands and the setup window.
Project page: https://github.com/warcrafted-server/AskForever

AskForever - asistente de IA dentro del juego para World of Warcraft: WoW Forever
El addon por sí solo genera un prompt con el contexto de tu personaje que puedes
copiar. Para recibir respuestas dentro del juego, mantén abierto el programa
gratuito AskForever companion para Windows o Linux mientras juegas.
Descárgalo de:
https://github.com/warcrafted-server/AskForever/releases
Guía de instalación para Linux (primera beta):
https://github.com/warcrafted-server/AskForever/blob/main/docs/INSTALACION_LINUX.md
El companion necesita una clave gratuita de la API de Google Gemini: créala antes
y, la primera vez que abras el companion, te pedirá que la pegues.
La carpeta docs/ incluye la guía de instalación completa y el informe de
seguridad y transparencia de datos: docs/INSTALL_GUIDE.md,
docs/GUIA_INSTALACION.md, docs/SECURITY_TRANSPARENCY.md,
docs/SEGURIDAD_TRANSPARENCIA.md.
En el juego, escribe /af help para ver los comandos y la ventana de instalación.
