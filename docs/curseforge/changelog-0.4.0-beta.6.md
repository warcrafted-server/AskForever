**Beta 11 — Best-in-slot gear answers.**

- Ask for the BiS or the best gear of a class and specialization (for example "best gear for an Arcane Mage") and the assistant lists the best item for each slot and where it drops, from the guide data.
- Data exists for 13 of the 27 specializations; for the others the assistant tells you which ones are available.
- The companion app updates itself, no reinstall needed.

**Beta 11: respuestas de equipo BiS.**

- Pregunta por el BiS o el mejor equipo de una clase y especialización (por ejemplo «mejor equipo para un mago arcano») y el asistente lista el mejor objeto de cada ranura y dónde se consigue, a partir de los datos de las guías.
- Hay datos de 13 de las 27 especializaciones; para las demás, el asistente indica cuáles están disponibles.
- La app del companion se actualiza sola, sin reinstalar.
